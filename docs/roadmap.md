# 功能状态与路线图

本页依据当前代码整理。“已实现”表示存在对应业务路径，不表示任意部署环境都已验收。已完成三个 Docker 镜像的本地构建与独立容器检查，范围见[部署指南](deployment.md)；完整 Compose 部署、真实提供方联调和真机安装测试仍待执行。

## 当前实现

| 范围 | 已有能力 | 使用边界 |
| --- | --- | --- |
| 应用 | Android / iOS、平台开关、Debug / Release 包标识、归档与恢复 | 包标识按应用、平台和模式校验 |
| 身份与权限 | 本地救援管理员、飞书登录、全局管理员、应用维护者、下载身份、会话撤销 | 管理权限与私有下载资格独立；没有独立的本地团队账号体系 |
| GitHub | PAT / GitHub App、仓库绑定、Release 完整快照、规则导入及定时检查 | 普通规则导入为 Debug 条目，不自动发布正式版本 |
| 安装包库 | 分片上传、SHA-256 校验、独立 APK / IPA 解析、GitHub 来源持久化 | 依赖 Worker 与隔离 parser；IPA 解析不等于设备安装授权 |
| 版本与发布 | 正式包、版本、按平台发布、默认版本、下架、公开副本收回 | 入库和发布是独立操作；云侧收回可失败 |
| 文件存储 | 本机、私有 COS / OSS、独立云公开副本 | 无通用 S3 / MinIO、自定义 CDN；公开桶不能启用或曾启用版本控制 |
| 下载 | 飞书资格检查、临时授权、本机 HEAD / 单 Range、固定页面分享 | 临时链接可在有效期内转发；不能收回已下载文件 |
| Actions 与通知 | 规则令牌、构建来源复核、逐阶段结果、飞书群卡片 | 仅群通知；未知投递不自动重发 |
| 任务与运维 | 持久任务、调度恢复、审计、健康状态、有限分发统计 | 授权与传输记录不代表安装量，云直链读取未纳入统计 |

## 已知限制与优先改进

1. **反代后的登录限流。** 默认 Uvicorn 禁用代理头解析，同一 Caddy 后的用户共享来源 IP 限流；需要受信代理范围与实际客户端 IP 的配套实现和测试。
2. **发布与部署验证。** 需要建立镜像发布、完整 Compose 冒烟、升级及一致备份恢复演练，并记录经过验证的版本和平台。
3. **外部服务验收。** 需要可重复的飞书、GitHub Actions、COS / OSS 验收流程，覆盖权限撤销、来源替换、投递未知及公开副本收回失败。

## 尚未实现的方向

- Android 按用户或比例灰度、稳定通道指针、客户端自动更新协议。
- TestFlight 接入与构建同步。
- 按用户或部门配置的细粒度下载策略，以及个人通知。
- 通用 OIDC、海外 Lark、GitHub Enterprise Server 和通用 S3 接入。
- 开箱即用的多机共享存储及高可用部署。

以上是候选方向，没有承诺发布日期；在具备实现、测试和真实链路证据前，不应对外宣称支持。

- 对源码、测试夹具、构建配置、历史提交和发布附件分别检查密钥、生产地址、内部标识及个人信息；采用受控扫描，避免在日志中输出命中内容。
