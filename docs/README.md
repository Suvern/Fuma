# Fuma 文档

Fuma 是面向飞书团队的自托管移动端安装包管理与分发工具。本目录说明当前代码的使用方式、运行边界与开发约定。

| 文档 | 适用场景 |
| --- | --- |
| [开发指南](development.md) | 安装依赖、启动本地服务、运行隔离测试、修改接口 |
| [部署与运维](deployment.md) | 配置 Compose、HTTPS、持久卷、备份和升级 |
| [当前架构](architecture.md) | 理解服务职责、包处理、权限和持久任务 |
| [第三方接入](integrations.md) | 配置飞书、GitHub、Actions 和 COS / OSS |
| [功能状态与路线图](roadmap.md) | 区分已实现能力、已知限制和后续方向 |

代码存在、自动化测试通过与真实环境验收是不同的结论。部署前应在目标环境验证登录、上传解析、发布下载、通知及备份恢复，不将接口可访问视为全链路可用。
